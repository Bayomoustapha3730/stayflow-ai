# Customer Onboarding Checklist

## Required

- Organization profile confirmed
- Active plan confirmed
- First property created
- At least one owner/admin present
- AI provider readiness confirmed (or deterministic fallback acknowledged)
- First knowledge item created
- Readiness checks pass

## Optional

- Team invitations sent (or skipped)
- WhatsApp setup completed (or skipped)
- Demo data generated (or skipped)

## Success Experience

After completion, the user should be able to navigate to:

- Host Inbox
- Property Knowledge
- WhatsApp Settings
- Billing
- Team Settings

## Product Behavior

- Incomplete tenants receive non-blocking onboarding resume prompt.
- Completed tenants continue to normal destinations.
- Users without admin privileges receive safe read-only messaging for admin-only steps.
